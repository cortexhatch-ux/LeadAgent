# Open Source Credits

LeadAgent is built on the shoulders of these projects:

## Backend (Python)

- [**KuzuDB**](http://kuzudb.github.io/docs) — embeddable graph database powering cross-project memory
- [**AgentMemory**](https://github.com/rohitg00/agentmemory) — semantic storage and indexing layer
- [**FastAPI**](https://fastapi.tiangolo.com/) — high-performance routing gateway
- [**Pydantic**](https://docs.pydantic.dev/) — strict data integrity
- [**Pexpect**](https://pexpect.readthedocs.io/) — terminal interaction for subscription CLIs

## CLI (Go)

- [**Glamour**](https://github.com/charmbracelet/glamour) — ANSI-highlighted markdown rendering
- [**Lip Gloss**](https://github.com/charmbracelet/lipgloss) — terminal UI styling
- [**Chroma**](https://github.com/alecthomas/chroma) — universal syntax highlighting

## Related Projects

- [**OpenCode**](https://github.com/anomalyco/opencode) — fully open-source, terminal-native AI coding agent
- [**Mysti**](https://github.com/DeepMyst/Mysti) — VS Code extension bringing multiple AI providers into collaborative brainstorm mode
